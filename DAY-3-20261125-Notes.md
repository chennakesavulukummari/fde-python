# Understanding file management
Python can perform the following operations:

Operation	        Python functionality
Create a file	    open()
Read a file	        read()
Write a file	    write()
Append content	    Append mode (a)
Delete a file	    Path.unlink()
Rename a file	    Path.rename()
Copy a file	        shutil.copy()
Move a file	        shutil.move()
Create directory	mkdir()
Delete directory	rmdir()
List files	        iterdir()
Check file exists	exists()

# 2. File opening modes

Python provides different modes when opening files.

Mode	Description
r	    Read
w	    Write (overwrites existing content)
a	    Append content
x	    Create a new file; fails if it exists
rb	    Read binary
wb	    Write binary
r+	    Read and write

Example: Create and write a file

file = open("application.txt", "w")

file.write("Welcome to Cloud Binary\n")
file.write("Python for FDE Engineers")

file.close()
